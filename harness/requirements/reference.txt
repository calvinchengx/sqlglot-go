# What the reference needs to BE the reference, hash-pinned.
#
# sqlglot folds dates through dateutil's relativedelta, imported lazily and
# behind a decorator that catches the ImportError -- so without this, the
# "reference" is a quieter version of it and regenerating the expectations
# silently loses every date fold. Unpinned, though, it is also whatever PyPI
# serves that day: python-dateutil 3.0.0 landed on 2026-10-21. The job this
# feeds exists to prove the expectations are exactly the pinned reference's,
# and a floating dependency puts a second, unpinned input into that proof.
#
# The hashes below are every artifact PyPI published for the exact release, so
# the file installs on any runner or developer platform, and
# `pip install --require-hashes` refuses anything that is not one of them.
# To move a version, change the pin and refresh its hashes from
# https://pypi.org/pypi/<name>/<version>/json.
#
#   pip install --require-hashes -r harness/requirements/reference.txt

# folds the dates; the reference imports it lazily, behind a decorator that
# swallows the ImportError

    --hash=sha256:7ebcb3c29a92f3ceafe79a7a48a5c45677e9e004bbeec5742ac0bbb00560b7a2
